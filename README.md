## 产品链路

```
首页（未完成任务优先）
  → 创建任务（选相册来源，先选照片后命名）
  → 出片转场（打印→落堆 · 峰值 1：惊喜）
  → 卡片筛选（左滑放下 / 右滑留下，单次 60 张，可分批）
  → 详情页（结果与进度共存）
  → 生成作品集（选风格 → 视频 + 长图 · 峰值 2：感动）
  → 分享（扩散）→ 打印钩子（变现）
```

## 五条产品原则

| 编号 | 原则 |
|---|---|
| P1 | 决策越少越好（主链路决策点 ≤ 5 个） |
| P2 | 等待必须被看见（禁止孤立 Loading） |
| P3 | 措辞塑造价值（用「留下 / 放下」，不用「喜欢 / 不要」） |
| P4 | 分享物是一等公民（任何功能不得损害分享物完成度） |
| P5 | 峰值即转化（商业入口嵌在情绪峰值，不做独立商城） |
