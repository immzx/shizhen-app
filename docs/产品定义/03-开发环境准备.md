# 拾帧 · 开发环境准备

> 版本 v0.1 ｜ 2026-09-04 ｜ 针对本机配置定制
> 本文件不是通用安装教程，而是**基于你机器实际约束**的方案。请先读第零节。

---

## 零、先说结论：你的机器有硬约束，方案必须绕开它

| 项目 | 你的机器 | DevEco Studio 官方要求 | 判定 |
|---|---|---|---|
| 物理内存 | **8 GB**（可用常低于 1.5 GB） | 最低 8 GB / **推荐 16 GB** | 勉强够最低线 |
| 模拟器 | — | **需要 16 GB 及以上** | **不可行** |
| 硬盘 | 需自行确认（官方建议 100 GB，最低 30 GB） | 100 GB 推荐 | 需检查 |
| 页面文件 | 约 9.86 GB（D 盘） | — | 可防崩溃，但**不能提速** |

### 由此得出的三条硬性结论

1. **不要安装和使用模拟器。** 它在 8 GB 机器上要么起不来，要么把系统拖到不可用。省下的 4–6 GB 是必须的。
   → 因此**真机调试不是可选项，是刚需**。你需要一台 HarmonyOS NEXT 的鸿蒙手机。
2. **必须做内存优化配置**（见第三节），否则 IDE 自身的堆设置会吃掉本就不多的内存。
3. **强烈建议加装一根内存条到 16 GB。** 这是整个项目投入产出比最高的一笔支出 —— 一次性投入，换回的是此后每一次编译、每一次预览的时间。以当前内存价格衡量，长期看是净收益。

> 关于页面文件的诚实说明：你 D 盘约 9.86 GB 的 pagefile 能防止「内存不足导致崩溃」，
> 但**不会让编译变快** —— 虚拟内存走的是磁盘，速度比物理内存低一到两个数量级。
> 它保的是「不崩」，不是「快」。

## 一、安装清单

| 组件 | 说明 |

## 二、安装步骤

1. 访问华为开发者官网下载中心，**登录华为账号**后下载 DevEco Studio。
2. 双击 `.exe` 启动安装向导。
   - **安装路径建议放在非系统盘（如 D 盘）**，前提是 D 盘有 ≥ 50 GB 可用空间；先看一眼磁盘余量再决定。
3. 首次启动时若弹出 Import Settings，选 **Do not import settings**。
4. 等待首次依赖同步与索引完成，约 20–40 分钟，期间保持网络稳定。
5. 验证环境（在 DevEco 内置终端执行）：

```bash
# 验证构建工具
hvigorw --version

# 验证包管理器
ohpm --version
```

## 三、8 GB 内存下的优化配置（**必做**，否则体验会很差）

### 3.1 调低 IDE 自身堆内存（最关键的一步）

DevEco 基于 JetBrains 平台，默认堆上限对 8 GB 机器偏高。

操作：`Help → Edit Custom VM Options`，调整：

```
-Xmx1536m
-Xms512m
```

> 若后续发现编码卡顿可小幅上调至 2048m，但**不要超过 2048m**，否则会挤占构建进程所需内存。

### 3.2 禁用模拟器与无关插件

- `File → Settings → Plugins`：关闭 Android、iOS、Flutter 等一切与鸿蒙无关的插件。
- SDK 管理中**不勾选 / 不安装 HarmonyOS Emulator**。
- 关闭 IDE 的「Code Completion 自动弹窗」与实时检查中的高耗项（可保留手动触发）。

### 3.3 使用习惯

- 开发时**关闭浏览器、设计软件、通讯软件**等占内存应用 —— 浏览器通常是最大的内存占用源。
- **优先使用 Previewer（预览器）做 UI 与静态布局调试**，它比模拟器轻得多，但仍远慢于真机。
- 真机运行一次的成本低于反复预览，逻辑与动效验证直接上真机。

## 四、真机调试配置（必需，因为不能用模拟器）

1. **手机端**：设置 → 关于本机 → 连续点击「版本号」7 次，开启开发者模式。
2. 进入「系统和更新 → 开发人员选项」，开启 **USB 调试**。
3. **华为开发者账号**：需完成实名认证（自动签名依赖账号登录）。
4. **自动签名**：`File → Project Structure → Signing Configs` → 勾选 **Automatically generate signature**。
5. 用 USB 连接手机，选择「传输文件」模式，授权本机的调试指纹。
6. 验证设备识别：

```bash
hdc list targets
```

能列出设备序列号即配置成功。

## 五、项目初始化建议

| 配置项 | 选择 |
|---|---|
| 模板 | Application → **Empty Ability** |
| Language | **ArkTS** |
| Model | **Stage**（不要用 FA 模型） |
| Compile SDK | 最新稳定版 |
| Device | Phone |

### 建议的工程目录结构（针对拾帧）

```
entry/src/main/ets/
├── entryability/       # 应用入口与生命周期
├── pages/              # 页面（首页 / 创建 / 出片 / 筛选 / 详情 / 生成）
├── components/         # 可复用组件（卡片堆、出片动画、进度环等）
├── model/              # 数据模型（Photo、Collection、Selection、Portfolio）
├── service/            # 系统能力封装（PhotoAccessKit、MediaKit、存储）
├── animation/          # 动效参数与曲线集中管理
└── common/             # 常量、设计 Token、工具
```

> 建议把**动效参数（时长、曲线、延迟、间距）集中在一处管理**。
> 出片转场这类多段关键帧动画，参数会反复调整几十次，散落在页面里会难以维护。

## 六、针对拾帧的特别提醒

| 事项 | 说明 |
|---|---|
| **权限申请** | 读相册需 `ohos.permission.READ_IMAGEVIDEO`；保存长图/视频需 `ohos.permission.WRITE_IMAGEVIDEO`。两者均需在 `module.json5` 中声明并向用户申请 |
| **动效性能** | 出片动画的帧率**只能在真机上测**。Previewer 与模拟器的帧率不可信，不作为判断依据 |
| **视频合成内存峰值** | 这是 8 GB 机器上的头号测试重点。**必须在最低支持机型上实测**，开发机内存不足不构成豁免理由 |
| **大批量照片** | 读取后务必降采样，不要直接加载原图；列表用 `LazyForEach`，禁止一次性构建全部组件 |

## 七、常见问题速查

| 现象 | 排查方向 |
|---|---|
| SDK / 依赖下载失败 | 网络稳定性；必要时配置代理（Settings → HTTP Proxy） |
| `hdc list targets` 无设备 | USB 调试未开 / 未授权本机指纹 / 驱动异常 / 数据线仅充电 |
| 构建报 hvigor 或 ohpm 错误 | 确认未混用系统 Node；使用 DevEco 内置工具链 |
| 签名失败 | 华为账号未登录或未实名；尝试重新生成签名 |
| IDE 极度卡顿 | 回到第三节；同时检查是否有其他进程占用大量内存 |

---

## 八、下一步依赖的确认项

1. **是否已有 HarmonyOS NEXT 真机** —— 若无，真机调试无法进行，需在阶段 5 前解决。
2. **磁盘可用空间** —— 决定是否将 DevEco 装在 D 盘。
3. **目标 API 版本 / 最低支持机型** —— 决定可用 API 与兼容性下限。
