# 拾帧 · 分享物规格

> 版本 v0.1 ｜ 2026-09-04 ｜ 状态：待评审
> 依据《01-产品定义》P4（分享物是一等公民）与 P5（峰值即转化）。
> **本文件是产品的第一优先级交付物规格** —— 分享物决定了作品集要生成什么，作品集决定了选片要产出什么。

---

## 一、为什么分享物要先行

用户拿给外人看的，只有分享物。它同时承担三件事：

1. **扩散**：决定新用户从哪来、K 因子能到多少；
2. **留存**：用户自己会把成品保存下来，这是他留下的唯一纪念物；
3. **变现**：用户对「印出来是什么样」的想象，全部来自分享物。

因此分享物不是一个「导出功能」，它是**产品的最终形态**。

## 二、形态选型：A + B 双产物

### 2.1 三种候选形态对比

| | **A · 竖版短视频** | **B · 竖版长图** | **C · H5 交互页** |
|---|---|---|---|
| 载体 | 9:16 视频，12–18 秒 | 1080 宽、高度自适应 | 网页链接 |
| 传播 | 朋友圈/视频号/抖音原生支持，动态感染力最强 | 朋友圈以图片形式展示，点开即看 | 朋友圈仅显示链接卡片，内容不可见 |
| 生成 | 需视频合成（MediaKit），耗时、耗电 | 绘制即可，秒级完成 | 需服务器与网页托管 |
| 保存/打印 | 不可直接打印 | **可直接作为印刷排版稿** | 不可打印 |
| 技术成本 | 高 | **低** | 中（含后端） |
| 风险 | 生成失败的挫败感、机型兼容 | 信息密度低于视频 | 微信内跳转流失率高 |

### 2.2 结论：**A 为主（承担扩散），B 为辅（承担留存与打印），共用一套排版模板**

关键判断 —— **长图不是视频的附属品，长图就是印刷排版的前置产物。**

用户在手机上看到的长图版面，与将来印出来的摄影集版面，应当是**同一套设计资产**（同样的网格、留白、字体、页序）。这样带来三个直接收益：

1. 打印转化率提升：用户「已经看见成品的样子」，无需想象，决策成本大幅下降；
2. 设计与开发成本减半：一份排版模板，两处产出（视频帧 / 长图 / 印刷稿）；
3. 打印链路零额外设计：印刷端可直接复用长图的分页数据与版式参数。

> 这条把「分享」与「打印」两件原本割裂的事，用同一份设计资产串成了闭环。
> 它不是巧合 —— 因为**用户想分享的样子，就是他想留下的样子。**

### 2.3 暂不选 C 的理由

H5 在朋友圈内表现为链接卡片，内容不可见，扩散效率显著低于视频与图片；且引入服务器成本。**二期若需要更强的回流追踪与「一键做同款」能力，再考虑以短链形式补充**，不作为一期产物。

## 三、产物 A：竖版短视频

| 项 | 规格 | 说明 |
|---|---|---|
| 分辨率 | 1080 × 1920（9:16） | 兼容朋友圈/视频号/抖音 |
| 时长 | **12–18 秒** | 朋友圈黄金区间；超过 20 秒完播率明显下降 |
| 照片数 | 8–15 张 | 15 张 × 1.2 s ≈ 18 s，为上限 |
| 单张停留 | 1.2–1.8 s | 按风格与照片横竖比微调 |
| 首帧 | 0.8 s 标题卡 | 内容：摄影集名 + 日期区间 + 张数 |
| 尾帧 | 1.5 s 品牌卡 | 内容：极小品牌标识 + 钩子文案 + 「我也要做」引导 |
| 音乐 | 内置 3–5 首，按风格匹配 | **必须使用免版税或自制音源**，商用授权需提前确认 |
| 转场 | 按风格区分（见第五节） | 与生成风格严格绑定 |

**关键约束**：生成成功率必须 ≥ 99%。移动端视频合成的失败风险（内存、时长、编码）远高于图片绘制，需设计降级路径 —— **合成失败时自动降级为产物 B（长图），并以同等仪式感呈现，绝不能只弹「生成失败」。**

## 四、产物 B：竖版长图

| 项 | 规格 |
|---|---|
| 宽度 | 1080 px（高度按张数自适应，上限约 6000 px） |
| 版式 | 大留白；照片下方配极小字号的元信息（日期 / 地点 / 文件名，取可得者） |
| 页序 | 与视频帧序、印刷页序**严格一致** |
| 末尾 | 品牌条 + 钩子文案，高度占比 < 1.5% |
| 输出 | 保存至系统相册（PhotoAccessKit 写权限） + 分享至微信 |

## 五、三种风格对分享物的影响

| 风格 | 视频表现 | 长图表现 | 转场/版式策略 |
|---|---|---|---|
| **光影电影感** | ★★★ 优势最大 | ★★ | 暗场、大留白、缓慢推镜（Ken Burns）、字幕式文案、宽幅黑边 |
| **简约画册感** | ★★ | ★★★ 优势最大 | 白底、严格网格、衬线字体、无转场特效、最接近真实印刷品 |
| **胶片氛围感** | ★★★ | ★★ | 颗粒质感、日期戳（橙色 LED 字体）、白边框、轻微漏光 |

> 风格选择既是审美选择，也是「视频 vs 长图」的权重选择。后续可在生成结果页同时给出两个产物，由用户自行选择分享哪一个。

## 六、品牌露出策略（决定扩散率的细节）

### 6.1 原则

让看的人产生「**我也想做**」的欲望，而不是「这是个广告」。

### 6.2 具体规格

| 位置 | 规格 |
|---|---|
| 视频尾帧 | 1.5 s，底部小字 + 「我也要做」引导，品牌标识高度占比 < 8% |
| 长图末尾 | 品牌条高度占比 < 1.5%，置于右下角 |
| **禁止** | 满屏 Logo、强制片头、遮挡照片的水印、不可关闭的角标 |

### 6.3 钩子文案：用数据，不用口号

**推荐文案格式：**

> 这 15 张，是从 832 张里挑出来的。

理由：

- 这是产品**天然生成的数据**，零额外成本；
- 数字比形容词更可信，也更能激发好奇心（「我也能挑出我的 15 张吗」）；
- 「832 → 15」的反差本身就是产品价值的最短表达；
- 不喊口号、不露广告相，完全符合 P4。

> 备选：「2026 年的 8 月，我留下了 15 帧。」（偏文艺，适合胶片风格）

## 七、回流路径

```
看到分享物 → 点击/扫码
   ├─ 未安装 → 引导至鸿蒙应用市场下载 → 落地首页空状态引导（承接同一期待感）
   └─ 已安装 → 直接打开该「风格模板」→ 进入创建流程（跳过风格选择，降低一步决策）
```

**关键细节**：已安装用户应直接落在**他看到的那个风格模板**上，而不是 App 首页。这一处跳转优化预计能显著提升激活率 —— 因为用户的动机是具体的（「我也要做这个风格的」），而非抽象的。
