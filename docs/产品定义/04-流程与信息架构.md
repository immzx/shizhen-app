## 一、产品链路与页面地图

### 1.1 总链路（承接 PROGRESS 二节）

```
首页（未完成任务优先）
  → 创建任务（先选照片，后命名；名称自动生成）
  → 出片转场（打印 → 落堆，峰值 1：惊喜）
  → 卡片筛选（留下 / 放下，单批 60 张，可分批、可中断续做）
  → 选片完成（成就：你留下了 N 张 + 统计）
  → 生成作品集（选风格 → 视频 + 长图，峰值 2：感动）
  → 成品结果（预览 / 保存 / 分享 / 打印钩子）
```

### 1.2 页面地图（主链路 8 页 + 二级页）

| 编号 | 页面 | 类型 | 一句话职责 |
|---|---|---|---|
| P1 | 首页 | 主 | 续做优先：未完成任务置顶、历史成品可回看 |
| P2 | 创建任务 | 主 | 选定本次要筛的照片集合 + 命名（自动生成，可改） |
| P3 | 出片转场 | 主（过渡） | 把候选照片「打印」成物理卡片堆——峰值 1 |
| P4 | 滑卡筛选 | 主 | 一票否决逐张判定；批次推进；核心心流页 |
| P5 | 任务详情 | 主（枢纽） | 结果与进度共存：已留下集合、续做入口、生成入口 |
| P6 | 生成 | 主（过渡） | 选风格 → 有信息量的生成过程 → 峰值 2 首映 |
| P7 | 成品结果 | 主 | A 视频 / B 长图的预览、保存、分享、打印钩子 |
| P8 | 打印预约 | 二级（**一期暂缓**） | 心愿登记（尺寸 / 数量意向），不接支付（D5）——二期启用，见第七节 |
| S1 | 我的作品集 | 二级 | 历史成品列表（入口：P1） |
| S2 | 系统权限引导 | 二级（条件触发） | 相册读写权限被拒时的引导与跳转设置 |
| S3 | 曲库与版权 | 二级 | 内置曲库来源说明（D3 合规） |

> 主链路各页在 Navigation + NavPathStack 中为路由页；P3、P6 是可全屏覆盖的过渡路由（转场本身即体验，非弹窗、非加载页）。

## 二、页面清单：职责、入口、出口

> 每页列出：**职责**（这页只负责什么）、**入口**（从哪来）、**出口**（去哪、条件）、**关键决策点**（用于 P1 计数）。

### P1 首页

| 项 | 内容 |
|---|---|
| 职责 | ① 把「未完成任务」以进度卡置顶（续做的钩子）；② 历史成品入口；③ 新任务入口 |
| 入口 | 冷启动 / 回流落地（02 七节：已装用户带 style 参数落到创建流程，绕过首页） |
| 出口 | → P2（新任务）；→ P5（点未完成任务卡）；→ S1（点「我的作品集」）；→ P7（点某份成品） |
| 布局（示意） | 「未完成任务」横向进度卡组（名称 / 已判 X / 总 N / 续做按钮）→「最近成品」宫格 → 底部主按钮「挑一组新的」 |
| 关键决策点 | 0（新任务按钮是唯一新增入口；续做 / 回看均非决策） |
| 备注 | 冷启动无任何任务时走第五节空状态；数据卡片语气遵守 P3（「还剩 240 张等你决定」而非「未完成」） |

### P2 创建任务

| 项 | 内容 |
|---|---|
| 职责 | ① 选择照片来源与范围；② 多选/整选照片；③ 生成名称并确认建档 |
| 入口 | P1「挑一组新的」；回流（02 七节，携带 style，落在同页并预置风格） |
| 出口 | → P3（确认后即触发）；返回 → P1 |
| 步骤 | **① 选范围**（按相册 / 按时间段 / 手动多选，系统相册语义分组）→ **② 确认集合**（显示张数 + 预计分批数「将分成 X 堆，每堆 60 张」）→ **③ 命名**（自动生成如「八月·海边」，可改可不改）→ ④ 开始 |
| 关键决策点 | 1（选照片集合）+ 0.5（命名：有默认值，改动才算决策）≈ **1.5 个** |
| D13（已拍板） | **候选集合上限 600 张**（10 批）：再多会显著拉低「滑到最后一张」的完成率，与筛选环节 KPI 冲突；超限时提示缩小范围 |
| 备注 | 名称会成为作品集首帧标题卡（02 三节：摄影集名 + 日期区间 + 张数），故自动生成规则与标题卡同源 |

### P3 出片转场（峰值 1）

| 项 | 内容 |
|---|---|
| 职责 | 把抽象「已选照片」变为可触摸的**物理卡片堆**：打印 → 落堆 → 顶卡放大。用户在此第一次「摸到」照片 |
| 入口 | P2 确认建档 |
| 出口 | → P4（首批就绪即进入；不等全部材料备好） |
| 设计要点 | ① 物理隐喻：厚度、阴影、遮挡关系（PROGRESS 七节技术备忘）；② 首批 60 张就绪即可滑，其余后台继续备；③ 超过 1s 的准备时间全部转化为「打印动画」本身（P2 禁止孤立 Loading）；④ 动画期即任务态「准备中」 |
| 关键决策点 | 0（纯观看） |
| 备注 | 性能硬指标：≥ 55 fps、中端 ≥ 45 fps（01 五节）。此处是首因印象，掉帧不可接受 |

### P4 滑卡筛选（核心心流页）

| 项 | 内容 |
|---|---|
| 职责 | 一票否决（D6）：左滑**放下** / 右滑**留下**；维护批内进度与全局进度；支持撤销与中断 |
| 入口 | P3（首批就绪）；P5「继续筛选」（中断续做定位到未判第一张） |
| 出口 | → P5：a) 滑完一批后用户点「回详情」；b) 全部候选判完 → 先落 P5 成就态；c) 任意时刻退出（已判结果即时持久化） |
| 关键决策点 | 每张 1 个（留 / 放），属筛选本身不计入 P1 配置决策 |
| 界面要素 | 顶部：本批进度（第 X 堆）+ 全局进度（已判 N / 总 M）；中：卡片；底部或边缘：**撤销**（栈回放反向动画，可连续多次）、退出；计数以「留下 N 张」正向呈现（01 二节） |
| 手势细则 | PanGesture 跟手 translate/rotate；松手过阈值按方向飞出（springMotion），未过阈值回弹；飞出即判定并写盘；每张判定间隔保证动画完整（详见第六节批次交互） |
| 备注 | 卡片内容：照片 + 极小字元信息（日期 / 地点 / 文件名，取可得者，与 02 四节长图元信息一致——**选片时看到的元信息 = 成品里的元信息**，强化「所见即所得」） |

### P5 任务详情（结果与进度共存的枢纽）

| 项 | 内容 |
|---|---|
| 职责 | ① 展示已留下集合（缩略墙）与统计（处理总量 / 耗时 / 留下 N 张）；② 未完成时提供续做；③ 完成后提供生成入口与成品回看 |
| 入口 | P1 点任务卡；P4 批次完成 / 全部完成 / 中途退出落点；P7「回到任务」 |
| 出口 | → P4（继续筛选）；→ P6（生成）；→ P7（回看已生成成品）；→ P1（返回） |
| 三种子态 | **筛选中**：缩略墙为「已留下」，顶部「还剩 X 张待决定 · 继续」；**已完成未生成**：成就呈现（峰值后置，见下）+ 醒目「做成作品集」；**已生成**：成品卡片 + 「再看一遍 / 分享」直达 P7 |
| 成就呈现（01 四节） | 「你留下了 15 张」+ 处理总量与耗时统计（如「从 832 张里，留下了 15 张」——与钩子文案同源的数据）。此页是峰值 2 的**情绪起点**，文案与排版给足仪式感 |
| 关键决策点 | 1（生成 or 暂不生成——暂不生成是合法出口，任务留存在「已完成」供随时回来） |
| D14（已拍板） | **「已留下」缩略墙支持长按移除（撤销语义的延伸）**：只允许移除误留，不允许新增——新增需回到筛选的候选池，避免引入「事后挑选」的编辑心智 |

### P6 生成（选风格 → 首映，峰值 2）

| 项 | 内容 |
|---|---|
| 职责 | ① 选风格（3 选 1）；② 执行生成并让等待「有信息量」；③ 成品首映（感动顶点） |
| 入口 | P5「做成作品集」；回流（02：已装用户带 style 直达此风格，**跳过选择**，少一步决策） |
| 出口 | → P7（成品结果页，含保存 / 分享 / 打印钩子） |
| 风格选择 | 3 选 1（02 五节：光影电影感 / 简约画册感 / 胶片氛围感），每项带该风格下视频与长图的**迷你样貌预览**（非纯文字） |
| 生成过程（P2 关键） | 硬指标生成 < 8s、> 3s 必须有过程可视化（01 五节）。方案：**生成即排片预演**——把「正在为你排片 / 配乐 / 成帧」做成与成品同语言的分段动画（帧序逐张亮起 + 音乐渐进），用户看到的是作品在「被组装」，而非进度条 |
| 双产物 | 一次生成同时产出 A 视频 + B 长图（D1）；用户可自行选择分享哪一个（02 五节） |
| 失败处理 | 见 4.1（D9 自动降级，绝不只弹「生成失败」） |
| 关键决策点 | 1（选风格；回流场景为 0） |
| 备注 | 主链路累计配置决策点：P2 约 1.5 + P6 1 ≈ **2.5 ≤ 5**（P1 达标） |

### P7 成品结果

| 项 | 内容 |
|---|---|
| 职责 | ① A / B 双产物预览与切换；② 保存到相册；③ 分享微信（系统分享）；④ **打印钩子（对制作者）**；⑤ 分享物自带的「我也要做」（对观看者，02 六节） |
| 入口 | P6 首映完成；P1 / S1 回看历史成品；回流他人分享物（落地同款风格） |
| 出口 | → 分享面板（系统）；→ 打印钩子卡（一期点击为轻提示，见 7.4）；→ S1 / P1（返回）；→ P2（「我也要做」= 用同风格新建任务） |
| 布局（示意） | 视频/长图切换 Tab（默认视频）→ 成品预览区 → 操作条「保存 / 分享」→ 其下**打印钩子卡片**（见第七节） |
| 元信息一致性 | 成品长图、视频帧序、印刷稿共用同一套设计资产（D8）；此页预览即印刷稿版式预览——**「印出来就是这样」无需想象** |
| 备注 | 观看者视角的钩子埋在分享物内部（视频尾帧 1.5s 品牌卡 / 长图末尾品牌条），与制作者视角的钩子（本页卡片）是**两层不同钩子**，详见第七节 |

### P8 打印预约（钩子落地 · 一期暂缓）

> **评审决定（D15）**：一期**保留钩子卡**（P7 的转化点不丢），**暂缓登记落地**——点击钩子卡先显示轻提示「成册服务准备中」；P8 登记页的设计留作二期参考，全文保留如下。

| 项 | 内容（二期参考） |
|---|---|
| 职责 | 心愿登记：成册意向（规格 / 数量区间 / 联系方式），**不接支付、不承诺**（D5） |
| 入口 | P7 打印钩子卡片 |
| 出口 | → 登记成功态（含「印出来大概长这样」的印刷版式预览 = 复用同一套设计资产）→ 返回 P7 |
| 字段（尽量少，P1） | ① 册子规格意向（A5 / A4 或「还不确定」）；② 数量意向（1 本 / 2–3 本 / 送人）；③ 联系方式（电话 / 微信，选填）——**全部可跳过**，「先登记着」也成立 |
| 文案基调 | 承诺前置：「正式开放前会先给你确认版式与报价，无需现在付款」（降低决策成本，D5） |
| 一期行为 | 钩子卡点击 → 轻提示「成册服务准备中，开放时会先通知你」→ 留在 P7；不做表单、不留痕 |

## 三、全局状态机

### 3.1 任务五态（PROGRESS 给定枚举）

| 状态 | 含义 | 页面驻留 |
|---|---|---|
| **未开始** | 任务已建档（照片集合与名称已定），尚未进入出片 | P5（等待开始态） |
| **准备中** | 正在把候选照片「打印」成卡片堆（读取 / 降采样 / 布局） | P3 出片转场 |
| **筛选中** | 至少一张已判定，且仍有候选未判（含批间间隙与中断挂起） | P4 / P5 |
| **已完成** | 候选全部判定完毕，结果集定型；尚未生成或暂不生成 | P5（成就态） |
| **已生成** | 至少完成一次作品集生成（终态；可回看 / 重生成） | P5 / P7 |

### 3.2 状态转移

```
                       （回流/首页继续）
  ┌──────────────────────────────┐
  ▼                              │
未开始 ──开始筛选──▶ 准备中 ──首批就绪──▶ 筛选中 ──最后一张判定──▶ 已完成
  ▲                                │  ▲                        │
  │ 材料加载失败（可重试）            │  │ 中断退出/批间休息        │ 开始生成
  │                                │  └──────(回详情持久化)──────┘  ▼
  └──────(回详情)──────────────────┘                            生成中（任务态不变，子流程）
                                                                    │
                                                ┌─────── 失败（D9 降级长图）───────┐
                                                ▼                                ▼
                                             已完成 ◀──重试/换风格────────── 已生成
```

| 当前态 | 事件 | 下一态 | 条件 / 动作 |
|---|---|---|---|
| 未开始 | 用户点「开始筛选」 | 准备中 | 触发 P3 |
| 未开始 | 用户点「重新选照片」 | （回 P2） | 允许在建档后反悔一次（撤销语义） |
| 准备中 | 首批 60 张就绪 | 筛选中 | 进入 P4；其余材料后台继续 |
| 准备中 | 材料加载失败 | 未开始 | 可重试；连续失败走 4.3 异常流 |
| 筛选中 | 每张判定 | 筛选中 | 判定即时持久化（事务性，见 4.5） |
| 筛选中 | 批间 / 用户退出 | 筛选中 | 挂起；P5 提供「还剩 X 张 · 继续」 |
| 筛选中 | 最后一张判定 | 已完成 | 落 P5 成就态 |
| 已完成 | 点「做成作品集」 | 已生成 | 成功产出 A + B（或 B 降级） |
| 已完成 | 生成失败（非降级路径可覆盖） | 已完成 | 保留结果集，可重试；绝不让任务卡死 |
| 已生成 | 换风格重新生成（D16） | 已生成 | 新成品覆盖「最新」展示位；旧成品保留在 S1 历史 |
| 已生成 | 删除成品记录 | 已完成 | 仅删记录，不删相册原件、不动筛选结果 |

> D16（已拍板）：**允许「换风格重新生成」**——不动筛选结果，仅重新执行 P6。它把「已生成」从死胡同变成可再消费的情绪峰值，也为打印转化多留一次机会。与 D7 的边界：D7 约束的是「不可编辑成品内容」（不改文案 / 音乐 / 版式）；换风格是「用另一套风格重新生成」，不修改既有成品，旧版保留在 S1。

### 3.3 任务态 × 页面可用动作矩阵

| 动作 \ 状态 | 未开始 | 准备中 | 筛选中 | 已完成 | 已生成 |
|---|---|---|---|---|---|
| 查看已留下集合 | ✅ | — | ✅（进行中） | ✅ | ✅ |
| 继续筛选 | ✅（开始） | —（转场中） | ✅ | — | — |
| 生成作品集 | — | — | — | ✅ | ✅（重生成） |
| 回看 / 分享成品 | — | — | — | — | ✅ |
| 打印钩子（层 2） | — | — | — | — | ✅（一期为轻提示） |
| 删除任务 | ✅ | ✅ | ✅（须确认：会丢弃已判结果） | ✅ | ✅（须二次确认） |

## 四、异常流定义

> 原则：**任何异常都不得摧毁已建立的情绪峰值或已产出的结果。** 所有文案遵守 P3，不出现「失败」「错误」等责备式措辞（技术日志与埋点除外）。

### 4.1 视频合成失败（最高优先，对应 D1/D9）

| 项 | 内容 |
|---|---|
| 触发 | 生成阶段 A 视频合成失败（内存 / 编码 / 机型兼容，PROGRESS 判定为全流程技术风险最高一环） |
| 主路径 | **自动降级为产物 B（长图），以同等仪式感呈现**（D9）：首映流程不中断，P6 直接首映长图版本，P7 默认落在长图 Tab |
| 文案 | 呈现语：「这组照片先以长图与你见面」——**不解释技术原因、不指责设备**；若用户追问可展开技术说明（极小字） |
| 重试 | P7 提供低打扰的「生成视频版」入口（需要时再试）；连续失败第 2 次后该入口降级为「视频版稍后再试」并埋点 |
| 埋点 | 视频合成失败率（目标 ≥ 99% 成功率）、降级发生频率、降级后分享率（验证降级是否保住扩散） |
| 硬约束 | 禁止：只弹「生成失败」、模态报错框打断首映、任务态回退丢失结果 |

### 4.2 权限被拒

| 场景 | 首次拒绝 | 再次拒绝 / 永久拒绝 |
|---|---|---|
| 相册只读（READ_IMAGEVIDEO，P2 选照片时） | P2 内嵌说明条：解释「只读你选中的照片，用于挑出值得留下的」，按钮「允许」（重新拉起授权） | 引导 S2：按钮「去系统设置」跳转应用权限页；**不循环弹窗**；提供「从系统照片选择器选取」作为无整库权限的备选（PhotoViewPicker 单次授权路径，已列入 D10 技术验证） |
| 相册写入（WRITE_IMAGEVIDEO，P7 保存成品时） | 说明条 + 重试 | 降级路径：**保存不可用但分享照常**（分享走系统面板无需写权限）；S2 提供设置跳转；文案「先分享给重要的人，相册保存随时可开」 |
| 中途权限被收回（应用在后台被关权限） | 下次进入 P4 / P7 对应动作时按上述路径处理，任务数据不受影响 | 同左 |

> 关键：**读权限只在 P2 与续做时请求，写权限只在 P7 用户点「保存」时请求**——按需、就近，避免冷启动就要权限（违反 P1 的决策负担）。

### 4.3 照片读取失败

| 场景 | 处理 |
|---|---|
| 单张损坏 / 格式不支持 / 已被删除（滑卡中遇到） | **自动跳过，不出现在卡片上**；计入「处理总量」统计但不算判定。理由：坏照片不该占用用户的决策注意力 |
| 预加载期大量失败（> 20% 候选不可读） | 中止出片，回到 P5「未开始」并给出说明条：「有些照片暂时读不出来，检查一下云空间是否已下载」，可重试或重新选集合；已建档信息保留 |
| 华为云空间占位图（未下载原图） | 卡片上标注「原图待下载」小标；点击该卡触发下载并暂缓判定；用户可选择先滑下一张（⚠️ 技术细节列入阶段 5 验证） |

### 4.4 中途退出与恢复（D2「支持中断续做」的落地）

| 项 | 内容 |
|---|---|
| 退出时机 | P4 任意时刻（右上退出 / 手势返回 / 来电 / 切后台被杀） |
| 持久化 | **每张判定即写盘**（本地 DB 记录：taskId / 照片 id / 判定 / 批序 / 批内位置 / 时间戳）——不存在「未保存」窗口 |
| 恢复 | P1 未完成任务卡 → P5：显示「还剩 X 张待决定」，点「继续」→ 重新出片（材料已缓存则直接进 P4）→ **定位到未判第一张**（批序 + 批内位置双索引） |
| 恢复点体验 | 续做不重播峰值 1（已看过）——直接入 P4；若间隔很久（隔天）可给一行轻提示「上次你留下了 9 张」 |
| 批内位置恢复 | 若中断发生在批中，恢复后仍从该批未判处继续（不拆批、不重新洗牌） |

### 4.5 进程级异常

| 场景 | 处理 |
|---|---|
| 生成中进程被杀 | 生成记录标记「未完成」；下次进 P5 可一键重试；已产出的部分产物（如长图已生成）直接复用，不重复计算 |
| 判定动画中断（动画未播完即退出） | 以**落盘判定为准**（动画是呈现，判定在离手瞬间已写盘）；恢复后直接从下一张开始 |
| 本地数据损坏（极端） | 任务列表可重扫恢复：成品记录优先恢复（已分享物不可丢），筛选过程态可丢弃并提示重建 |

## 五、空状态设计

> 原则：**空状态是产品的第一句自我介绍，不是功能占位。** 语气遵守 P3，每个空态都给出「下一步做什么」的最小引导（01 四节：禁止空列表、纯功能入口罗列）。

### 5.1 冷启动首页（首次打开，无任务无成品）

| 层 | 内容 |
|---|---|
| 情绪 | 期待（01 四节） |
| 主区 | 一句话价值主张（「把一堆照片，变成一组作品」）+ 一张**内置样片作品集的迷你演示**（用 02 的分享物样稿资产做成的可播放小样，让用户 3 秒内看见成品长什么样——这是新用户理解产品最快的方式） |
| 主按钮 | 「挑 20 张最近的照片试试」——**带具体动作引导**（不是「开始」这种空泛词）；预置默认：最近照片 20 张、自动命名，用户只需点一下 |
| 次级 | 「从相册里慢慢挑」→ 进 P2 完整流程（对应 01 场景 3/4 的重度用户） |
| 权限前置 | 若相册权限未授权：主按钮前先出现一行权限说明 + 「允许访问照片」（见 4.2），授权后立即回到上述空态 |
| 底部 | 极小字：隐私承诺一句（「照片只在你的设备上处理」——降低决策成本，呼应不舍得删的心理） |

> 「挑 20 张」的数字来自 01 四节空状态引导；20 张 < 一批 60 张，保证首次体验在 1 分钟内走完一个完整闭环（选 → 出片 → 滑完 → 生成 → 分享）。

### 5.2 有任务无成品（用户创建过但没走完）

| 场景 | 空态设计 |
|---|---|
| 曾创建任务但从未开始 | 首页直接以该任务进度卡为主内容（不算空态）；若任务被删除 → 回到 5.1 |
| 任务全完成但从未生成 | P1 该卡显示「就差最后一步：做成作品集」——**临门一脚钩子**（生成转化率 ≥ 80% 的过程指标在此处承接） |

### 5.3 其它空态速查

| 位置 | 文案方向（示例，非最终） | 下一步 |
|---|---|---|
| S1 我的作品集（无成品） | 「你的第一本作品集，会从一组照片开始」 | → P2 |
| P5 已留下为空（全放下） | 不责备：「这组照片没有你要留下的——那就再挑一组」 | → P2 / 回 P4 撤销重滑（撤销栈仍可用） |
| P7 生成产物缺失（极端，如长图也失败） | 不显示报错框：回到 P5 并提供重试 | 重试生成 |

## 六、滑卡分批交互（D2 落地）

### 6.1 分批规则

| 项 | 规则 |
|---|---|
| 批大小 | 固定 **60 张 / 批**（D2）；最后一批不足 60 按实际 |
| 分批时机 | P2 建档时计算并告知（「将分成 X 堆，每堆 60 张」）——**先见全貌，再开始**，避免「看不到头」的焦虑 |
| 批内顺序 | 按拍摄时间**倒序**（最新在前，与「挑 20 张最近的照片」一致）；跨批不重排，批与批按时间连续 |
| 批与批 | 顺序推进，不可跳批；中断恢复定位到未判批的未判位置（4.4） |

### 6.2 批次切换过渡（核心：不打断心流）

| 阶段 | 设计 |
|---|---|
| 批末 | 第 60 张判定飞出动画完成后，**不出现弹窗、不切页** |
| 小结 | 顶部进度环短暂放大一瞬（0.6–0.8s），显示「这一堆，你留下了 N 张」——**正向计数**（P3），无「还剩 X 张没看」式催促 |
| 换堆 | 下一批卡堆从底部以「补牌」动效滑入（与出片落堆同一物理语言，P2）；首卡自动浮到可滑位置 |
| 全局进度 | 常驻呈现为「第 X 堆 / 共 Y 堆」+ 细进度条；本批进度为卡片堆剩余厚度（**隐喻式**：看着堆变薄，而不是盯着百分比） |
| 自动继续 | **批间不询问「是否继续」**——默认衔接下一批，用户可随时退出（右上角），把「继续」的决策负担换成「随时可走」的自由（P1；对齐 KPI「愿意滑到最后一张」） |
| 全批完成 | 最后一批末张判定后，过渡动画引向 P5 成就态（峰值 1 与成就感收尾，情绪不泄气） |

### 6.3 中途想停 / 回来

- 右上「收工」→ 直接回 P5（无确认弹窗，判定已落盘，无损失 → 无需「确认退出」这类防呆设计）；
- P5 该任务卡常驻「还剩 X 张待决定 · 继续」；
- 续做回来直接入 P4 定位未判处，不重播峰值 1（4.4）。

## 七、打印钩子：入口时机与文案

### 7.1 两层钩子（明确分工）

| 层 | 对象 | 位置 | 目标 |
|---|---|---|---|
| **层 1：分享物内钩子** | 看到分享物的**别人** | 视频尾帧 1.5s 品牌卡 / 长图末尾品牌条（02 六节规格） | 「我也要做」→ 回流（下载 or 用同风格创建） |
| **层 2：制作者钩子** | 正在看自己成品的**用户本人** | P7 成品结果页 | 「印出来」→ 钩子卡（一期轻提示，二期登记） |

> 本文件聚焦层 2 的入口时机与文案；层 1 规格已在 02 定稿，此处不重复。

### 7.2 入口时机（关键：峰值 2 之后，不抢峰值）

| 规则 | 说明 |
|---|---|
| 出现条件 | P6 首映完成、用户**看过一次成品**（视频至少播放到尾帧 / 长图至少完整滚过一遍）之后，才在 P7 呈现钩子卡 |
| 出现位置 | P7 成品预览与「保存 / 分享」操作条**下方**——低层、不遮挡、不弹窗；用户正在沉浸欣赏时不打断 |
| 强化时机（可选） | 用户点「保存到相册」成功后的轻提示 toast 旁，可带一句「印出来，是这份作品最完整的样子」——把「保存」动作顺势引向「留存」的实体化 |
| 禁止 | 生成前弹打印广告、P4 滑卡中插入钩子、首页常驻商城入口（P5 原则：不做独立商城 Tab） |

### 7.3 文案（数据型，遵守 02 六节）

| 位置 | 文案（示例） |
|---|---|
| P7 钩子卡标题 | 「这 15 张，是从 832 张里挑出来的。」 |
| P7 钩子卡副文案 | 把这组照片印成一册，拿在手里的分量不一样。 |
| P7 按钮 | 「我想印出来」（D5 用词即心智：先表达意愿，不涉及购买） |
| 一期点击反馈 | 轻提示「成册服务准备中，开放时会先通知你」 |
| 二期登记页预填（参考） | 自动带入本作品集的张数 / 风格 / 拍摄日期区间（用户零填写成本） |
| 二期承诺文案（参考） | 「成册开放前，会先给你确认版式与报价，无需现在付款。」 |
| 风格化备选（胶片氛围感时） | 「2026 年的 8 月，我留下了 15 帧。」（02 六节备选文案，随风格联动） |

### 7.4 一期行为与二期登记流

**一期（评审决定 D15）**：

```
P7 钩子卡（「这 15 张，是从 832 张里挑出来的。」）
  → 点击 → 轻提示「成册服务准备中，开放时会先通知你」→ 留在 P7
```

- 埋点：钩子卡曝光率、点击率（对齐 01 五节打印转化率 3–8% 目标漏斗的前端环节；一期无登记漏斗，先积累曝光 → 点击基线）；
- 一期不做支付、不做客服、不做站内推送（D5）。

**二期（P8 启用时）**：

```
P7 钩子卡 → P8 预约登记（规格意向 / 数量意向 / 联系方式，全部可跳过）
  → 登记成功态：印刷版式预览（复用同一套设计资产，D8「印出来就是这样」）
  → 返回 P7
```

- 启用时再补登记完成率埋点与触达策略（届时细化 D15 细则）。
