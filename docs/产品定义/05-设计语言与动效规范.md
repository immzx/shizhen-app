## 一、设计语言的定位与两条边界

### 1.1 一句话定位

**照片是演员，界面是暗下来的观众席。**

拾帧不做"信息丰富的工具界面"，而做"让照片几乎不被打扰地出现在眼前"的容器：
- 底色压暗、留白放大、文字克制（与 19 套方案里「深色影廊 / 黑曜石」路线的气质一致）；
- 信息层（进度、计数、按钮）以**毛玻璃浮层**形式轻悬于照片之上，可随时隐去。

### 1.2 两条必须遵守的边界（避免体系混淆）

| 边界 | 说明 |
|---|---|
| **UI 层 ≠ 内容层** | App 界面（首页 / 滑卡 / 结果页）是一套**恒定的暗色容器系统**；作品集内部（视频帧 / 长图版式 / 三风格）是另一套**内容排版系统**（02 第五节）。二者共用色彩语言，但互不侵入：**风格只改变作品集内部，不改变 App 的窗口与控件** |
| **照片不可被装饰** | 任何 UI 元素不得覆盖照片主体超过必要面积；分享物成品中的照片零水印（02 六节）；滑卡中照片只叠加滑动轨迹色，不加边框与角标之外的修饰 |

## 二、视觉基调：从 19 套方案中收敛

设计基线 19 套可归纳为三条路线。拾帧主链路（滑卡看照片 + 出片/生成的影院式氛围）天然偏向**深色路线**，浅色编辑部系留作二期候选。

### 2.1 三条路线与主推结论

| 路线 | 代表方案（19 套内） | 气质 | 与拾帧主链路的契合 |
|---|---|---|---|
| **深色影廊** | 深色影廊 / 黑曜石 / 沉浸式电影感 / 午夜电影感 | 安静、收藏感、照片即主体 | ★★★ 出片与首映的峰值氛围最自然 |
| **玻璃浮层** | 毛玻璃影像馆 / 烟熏黑曜石 / 系统画廊 | 照片作环境光、信息像冰晶悬浮 | ★★★ 信息层可隐可显，适合滑卡时全神贯注 |
| 浅色编辑部 | 暖白编辑部 / 象牙白编辑部 / 珍珠柔雾 | 纸张、杂志、人文温度 | ★★ 更适合二期"摄影手记"类场景 |

> ⚠️ **建议 D19（待评审）：一期 UI 采用「深色影廊 × 玻璃浮层」混合基调** —— 底色近黑压暗、
> 照片全屏呼吸；任务卡、进度、按钮等一切 UI 控件统一坐在毛玻璃浮层上。浅色编辑部系不进入一期。
> 依据：滑卡筛选与作品集首映都要求"目光只在照片上"（01 情绪地图的心流/感动段）。

### 2.2 深色基调的三档层次（贯穿所有页面）

| 层 | 用途 | 相对关系 |
|---|---|---|
| 底层 | 页面底色 / 照片承载面 | 最暗 |
| 内容层 | 照片本身（最高亮度来源） | 由照片决定，不调色不改亮度 |
| 浮层 | 毛玻璃信息层（导航 / 任务卡 / 按钮 / 进度） | 压在照片上，半透明、可辨识但不抢戏 |

> 视觉铁律：**界面上任何时刻，画面里最亮的区域必须是照片。** 所有 UI 色亮度均低于照片主体亮度。

## 三、色彩 Design Token

### 3.1 Token 结构（一期的全部颜色收敛为一组变量）

| Token | 值（主推） | 用途 |
|---|---|---|
| `bg/base` | `#07090D` | 页面最底层（近黑，带极微蓝） |
| `bg/surface` | `#0E141B` | 卡片 / 弹层等实体面板底色 |
| `bg/elevated` | `#141B24` | 悬浮更高层（如撤销条） |
| `glass/fill` | `rgba(255,255,255,0.07)` | 毛玻璃填充（叠在照片上） |
| `glass/border` | `rgba(255,255,255,0.10)` | 毛玻璃描边 1px |
| `text/primary` | `#F2F1EC` | 主文字（暖白，非纯白） |
| `text/secondary` | `rgba(242,241,236,0.62)` | 次级说明 |
| `text/tertiary` | `rgba(242,241,236,0.38)` | 弱提示 / 占位 |
| `accent` | `#AEB8A5`（低饱和银绿） | 激活、选中、留下方向、数据数字、进度 |
| `accent/ink` | `#141713` | accent 底上的反色文字 |
| `slide/keep` | `#AEB8A5` | 右滑"留下"轨迹色（同 accent） |
| `slide/drop` | `#8E9299`（中性冷灰） | 左滑"放下"轨迹色（中性，不暗示"删除"） |
| `danger` | `#B4685C`（低饱和） | 仅限破坏性动作确认（如删除任务） |
| `scrim` | `rgba(0,0,0,0.55)` | 峰值页 / 底部出现内容的压暗层 |

> 说明：a) 文字用暖白而非纯白，是 19 套方案中多数深色方案（ink `#F1F0EB`/`#F5F3EE`）的共性——纯白在暗底上刺眼；
> b) 全 UI **只保留一个 accent**（低饱和银绿），保证"少即是多"；c) "放下"用中性灰而非红，避免唤起"删除照片"的负面情绪（P3）。

### 3.2 备选 accent（评审时可换，结构与语义不变）

| 备选 | 色值 | 气质 | 对应 19 套方案 |
|---|---|---|---|
| 冷青 | `#9FC7FF` | 清透、科技、偏 iOS | 系统画廊 / 毛玻璃影像馆 |
| 暖金 | `#C9B58F` | 温润、胶片、偏收藏 | 深色影廊的暖银延伸 |
| 冰蓝（玻璃系） | `#ABDCFF` | 未来感、液态 | 液态湖光 |

> accent 一旦选定，全局只出现这一个强调色 + 中性色，不引入第二强调色。

## 四、字体与排版

| 项 | 规范 |
|---|---|
| 字体族 | **HarmonyOS Sans**（系统内置，不打包字体；数字建议用等宽数字特性避免跳动） |
| 字重 | 400（正文）/ 500（标题、强调）；**不使用 700+**（深色底高字重易发虚） |
| 字号阶梯 | Display 30 / 标题 22 / 正文 15 / 辅助 12 / 元信息 11（单位 vp，设计稿以 2× 出图） |
| 行高 | 标题 1.2–1.3，正文 1.5–1.6 |
| 数字排版 | 计数（留下 N 张 / 第 X 堆 / 处理总量）一律**等宽数字 + accent 色**，滚动变化有动效（见 6.5） |
| 标题卡 | 作品集首帧标题卡（02：摄影集名+日期区间+张数）由内容层排版定义，UI 层不干预 |
| 中西文混排 | 中文与数字/英文之间留半角空格（如"832 张"），正文不首行缩进 |

## 五、空间、圆角与毛玻璃

### 5.1 间距网格

- 基准 **4vp**，一切间距取 4 的倍数；页面安全边距 20vp（手机）/ 24vp（平板）。
- 滑卡页照片区**无边距全出血**（照片顶到边缘），信息浮层离边 ≥ 12vp。

### 5.2 圆角与线宽

| 对象 | 值 |
|---|---|
| 滑卡照片 / 大图容器 | 0（全出血）或 4vp 微圆（看是否有底） |
| 卡片（任务卡 / 结果缩略） | 16vp |
| 按钮 / 输入 | 12vp |
| chip / 标签 | 999（胶囊） |
| 描边 | 1px，`rgba(255,255,255,0.10)` 级，不描黑边 |

### 5.3 毛玻璃规范（本产品的标志性质感）

| 参数 | 值 | 说明 |
|---|---|---|
| blur | 20–28 | 让照片成为"环境光"但不失真（19 套 glass 路线共性） |
| fill | 见 3.1 `glass/fill` | 极低白透明度即可，**不要 30%+ 的厚玻璃** |
| 叠放原则 | 浮层 ≤ 2 层 | 照片 → 信息浮层 →（瞬时）弹层；禁止三级以上玻璃堆叠 |
| 性能 | blur 半径与层数受 55fps 红线约束 | 大面积长驻 blur 在低端机可降级为半透明实底（见第十节降级规则） |

## 六、动效规范

### 6.1 三条总则

1. **动效是叙事的一部分，不是装饰。** 每个动效要么在讲故事（出片、生成首映），要么在解释状态（批间、撤销），禁止无意义的漂浮动画。
2. **跟手优先于自动。** 手势类动效（滑卡、滚动、缩放）第一优先级是零延迟跟手，松手后的自动阶段才谈时长与曲线。
3. **可被跳过、可被降级。** 所有动效遵守系统"减弱动态效果"设置；低端机按第十节降级，不允许掉帧硬扛。

### 6.2 曲线定义（ArkUI `curves.*`，供阶段 5 spike 校准）

| 命名（文档内） | ArkUI 映射 | 用于 |
|---|---|---|
| `spring-bouncy` | `curves.springMotion(0.55, 0.85)` | 物理落定、卡牌飞离后的归位 |
| `spring-soft` | `curves.responsiveSpringMotion(0.8, 0.8)` | 缩放入场、弹层出现（比 bouncy 更克制） |
| `fade-smooth` | `curves.smoothMotion()` | 淡入淡出、浮层显隐 |
| `press-quick` | `curves.friction(0.6)` 或 120ms linear | 按压即时反馈 |
| `content` | 内容层由风格参数决定（02 五节） | 视频转场等由生成引擎实现，不属 UI |

### 6.3 动效时长总表

| # | 场景（对应 04 页面） | 时长 | 曲线 | 说明 |
|---|---|---|---|---|
| M1 | **出片·打印落堆**（P3） | 单卡 110ms，错峰 18ms/卡 | 落定 `spring-soft` | 卡片从底部"打印"冒出现象 + 逐张错峰堆叠；首批 ≥ 3 张就绪即可开滑（04 P3），其余后台继续 |
| M2 | **出片·顶卡放大**（P3 峰值 1） | 520ms | `spring-bouncy` | 第一张从堆顶放大到全屏可滑，Z 序提到最高（04 P3 物理隐喻） |
| M3 | **滑卡·跟手**（P4） | 手势驱动（0ms） | 直接绑定 translate/rotate | 触摸→位移延迟 < 50ms（01 硬指标）；照片随手指平移 + 最大 6° 旋转 |
| M4 | **滑卡·松手判定**（P4） | 飞出 300ms / 回弹 320ms | 飞出 `spring-bouncy`，回弹 `spring-soft` | 超过阈值按方向飞离并写盘判定；未过阈值弹簧回中 |
| M5 | **滑卡·下一张入场**（P4） | 200ms | 淡入 + scale 0.98→1 | 前卡离场与后卡入场交叉 60ms，保持连续感 |
| M6 | **批末小结环**（P4） | 700ms | `fade-smooth` | 顶部进度环放大一瞬，显示"这一堆，你留下了 N 张"（04 6.2） |
| M7 | **批次补牌**（P4） | 550ms | 落定 `spring-soft` | 下一堆从底部"补牌"滑入，与出片同一物理语言（04 6.2） |
| M8 | **撤销回放**（P4） | 240ms/张 | 反向 `spring-bouncy` | 按撤销栈逐张反向回放（PROGRESS 七节：栈回放反向动画） |
| M9 | **成就统计滚动**（P5） | 600–800ms | easeOut | "留下 15 张"数字滚动 + accent 点亮；文案出现先于数字滚动 |
| M10 | **生成预演**（P6） | 帧序亮起 120–150ms/帧，整体 ≤ 8s | 节奏跟随音乐 | 生成过程即"排片预演"（04 P6）：照片按成品帧序逐张亮起，音乐渐进；禁止进度条 |
| M11 | **首映标题卡**（P6 峰值 2） | 淡入 450ms，停留由内容层决定 | `fade-smooth` | 峰值 2 的起势；完成后接成品预览 |
| M12 | **页面转场**（全局） | 默认 push 320ms；峰值页 450ms | push：系统 standard；峰值页淡入 | 出片（P3）与首映（P6）用全屏淡入而非侧滑，制造"进入另一个空间"感 |
| M13 | **弹层 / 底部出现** | 出现 260ms / 消失 200ms | `spring-soft` 出，`fade-smooth` 入 | 撤销条、权限说明条、钩子轻提示 |
| M14 | **按压反馈** | 120ms | scale 0.97 | 所有可点元素（含照片卡边缘按钮）轻按收缩 |
| M15 | **钩子卡出现**（P7） | 500ms 上浮淡入 | `fade-smooth` | 峰值 2 之后才出现（04 7.2），不抢首映 |

> 以上数值为设计稿初值，**阶段 5 spike 用真机校准**（D12 真实素材到位后调 M1/M2/M3/M4 参数）。

### 6.4 关键场景的动效组合（写意级描述，供实现对齐）

- **出片（峰值 1，P3）**：底部逐张"打印"冒出 → 落成有厚度的卡堆（阴影与遮挡表现厚度）→ 顶部第一张缓抬放大至全屏 → 进入可滑状态。全程无进度条、无文字提示，纯物理叙事（04 P3：禁止孤立 Loading）。
- **滑卡判定（P4）**：右滑离手 → 卡飞出 + 轻微上抛，轨迹带 accent 色晕（"留下"）；左滑离手 → 冷灰轨迹（"放下"）。离手瞬间写盘，动画只做呈现（04 4.5）。
- **批次衔接（P4）**：堆滑空 → 顶部小结环放大（0.7s）→ 下一堆从底部补入（0.55s），全程不断流（04 6.2）。
- **生成首映（峰值 2，P6）**：P5 点生成 → 屏幕转暗（scrim）→ 帧序照片随音乐逐张点亮（M10）→ 首帧标题卡淡入（M11）→ 无缝进入成品预览。失败则按 04 4.1 降级长图、同一套呈现语言。

### 6.5 数字与计数的动效语言

计数（留下数 / 堆数 / 处理量）变化一律：旧数字在 80ms 内淡出上移 → accent 等宽新数字滚入（600–800ms）→ 短暂点亮后回落为常态 accent。禁止数字"闪现替换"。

## 七、文案语气（P3 的落地规范）

### 7.1 用词白名单 / 黑名单

| 语境 | ✅ 用 | ❌ 禁用 |
|---|---|---|
| 判定操作 | 留下 / 放下 | 喜欢 / 不喜欢 / 保留 / 删除 / 丢弃 |
| 结束一轮 | 收工 / 再看一遍 | 退出确认弹窗「确定删除？」 |
| 任务状态 | 待决定 / 已留下 / 已完成 | 未完成 / 待办 / 垃圾 |
| 照片集合 | 这一堆 / 这组照片 | 待删除队列 |
| 成品 | 做成作品集 / 再看一遍 / 印出来 | 导出 / 渲染完毕 |
| 出错 | （见 7.3，用正向承接） | 失败 / 错误 / 出错 / 无法加载 |

### 7.2 数据型文案规则（贯穿全局）

- 「留下 **N** 张」永远用真实计数（N 随判定实时 +1，见 6.5）；
- 需要总量语境时用反差格式：「从 **M** 张里，留下了 **N** 张」（M 取处理总量）；
- 堆进度表述：「第 X 堆 · 共 Y 堆」，不写"还剩 Z 张未看"式催促；
- 日期区间命名由自动生成规则产出（如「八月·海边」），用户可改（04 P2）。

### 7.3 关键文案位清单（语气基准，完整值见对应页面定义）

| 位置 | 语气与示例 |
|---|---|
| 冷启动首页空态（04 5.1） | 邀请式、带动作：「挑 20 张最近的照片试试」 |
| 权限说明（04 4.2） | 解释 + 行动：「只读你选中的照片，用于挑出值得留下的」 |
| 出片（P3） | **纯视觉不配字**，最多批标签「第 1 组」 |
| 成就（P5） | 克制祝贺 + 数据：「你留下了 15 张」→ 若总量大追加「从 832 张里」 |
| 视频降级（04 4.1） | 正向承接、不解释技术：「这组照片先以长图与你见面」 |
| 打印钩子（04 7.3） | 数据型 + 行动：「这 15 张，是从 832 张里挑出来的」/「我想印出来」 |
| 全放下的空态（04 5.3） | 不责备：「这组照片没有你要留下的——那就再挑一组」 |

### 7.4 系统级文案纪律

- **任何技术失败都不出现在用户可读文案里**（错误码只进日志/埋点）；
- 禁止一切「是否确认？」型反问（除了删除任务这类真正破坏性动作）；
- 文案统一小写英文数字（832 而非 八三二），句末不带感叹号堆叠（最多一个）。

## 八、内容层三风格与 UI 的关系（边界落地）

| 项 | 规范 |
|---|---|
| 内容层参数 | 光影电影感（暗场/宽幅黑边/缓慢推镜）、简约画册感（白底/严格网格/衬线/无转场）、胶片氛围感（颗粒/日期戳/白边框）——参数集见 02 第五节，不在此重复 |

## 九、性能红线（承接 01 五节）

| 指标 | 目标 |
|---|---|

## 十、降级与适配规则

| 触发 | 降级行为 |
|---|---|
| 系统开启"减弱动态效果" | 关闭 M1/M2/M6/M7 的物理弹簧，保留淡入淡出与跟手 |
